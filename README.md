## Question 1

The program uses the required 5x5 input and 3x3 filter, stride 1, and padding 0. It does not use a built-in convolution function. The filter is moved across every valid location and the element-wise products are summed.

Expected output feature map:

```text
[[4 3 4]
 [2 4 3]
 [2 3 4]]
```

Expected output shape:

```text
(3, 3)
```

With stride 2, the filter moves two positions at a time, so fewer locations are evaluated and the output feature map is smaller.

Run:

```powershell
python q1_convolution.py
```

## Question 2

The transfer-learning experiment uses the two-class `0` vs `1` subset of the scikit-learn Digits dataset and a standard pretrained ResNet18.

### Experiment A - Frozen Feature Extractor

All pretrained layers are frozen. The original 1000-class final layer is replaced by a two-class classifier. Only the new classifier is trained.

For ResNet18:

- Trainable parameters = **1,026**

### Experiment B - Fine-Tuning

The final ResNet18 convolutional block (`layer4`) is unfrozen together with the new classifier.

For ResNet18:

- Trainable parameters = **8,394,754**

The script uses the same number of epochs for both experiments and records training time and validation accuracy. It also creates the required training-loss plot and comparison CSV.

Run:

```powershell
python q2_transfer_learning.py
```

The pretrained ResNet18 weights may be downloaded automatically the first time the program is run.
